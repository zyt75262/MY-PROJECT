# CTB Project — BrightBite

## Download BrightBite for Windows

### [⬇ Download the Windows App](https://github.com/zyt75262/MY-PROJECT/releases/download/brightbite-v1.0.0/BrightBite-Windows.zip)

1. Download the ZIP file.
2. Extract it completely.
3. Double-click **BrightBite.exe**.

**No Python or PyCharm installation is required.**
Keep the small server window open while using the app.

## About BrightBite

BrightBite is a Python-based app featuring recipe browsing, favorites,
budget-based meal planning, and ingredient-based nutrition notes.

Meal planning uses demonstration prices. Nutrition notes provide
general information, not medical treatment advice.
