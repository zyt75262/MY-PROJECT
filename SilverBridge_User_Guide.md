## SilverBridge — Digital Support for Older Adults

### [⬇ Download SilverBridge for Windows](https://github.com/zyt75262/MY-PROJECT/releases/download/silverbridge-v1.0.0/SilverBridge-Windows.zip)

1. Download **SilverBridge-Windows.zip**.
2. Extract the ZIP completely.
3. Double-click **SilverBridge.exe**.

**No Python or PyCharm installation is required.**
Keep the small server window open while using the app.

### What SilverBridge Does

SilverBridge helps older adults request assistance with everyday
digital tasks. Users can submit text, screenshots, or audio.
Volunteers can claim requests, reply with instructions, and help
users track whether their problems have been solved.

The app also supports sharing local stories with permission.

### Sharing Between Devices

Run the server on one computer. Other devices on the same local
network can open the computer address shown in the server window.

Devices must connect to the same server to share requests and replies.
Separate computers running their own copies use separate databases.
Cross-region access requires a separately deployed public server.
